# Bezos Maritime Tracker — public artifact

This repository contains only the static public site and sanitized, delayed
data generated by the private collector. It intentionally excludes credentials,
raw logs, the SQLite database, and undelayed observations.

GitHub Pages should publish the repository root. The collector refreshes
`data/latest.json`, `data/track.geojson`, `data/events.json`, and
`data/events.rss` atomically.
